Generated by `gen/gen.janet` from raylib 5.5's headers (`api/*.jdn`) and `overrides.jdn`. Do not edit.

These names shadow Janet core bindings under `(use raylib)`; prefer `(import raylib :as rl)`: `load-image`.

- `UnloadRandomSequence`: freed by the binding when load-random-sequence returns
- `MemAlloc`: raw C allocation has no safe Janet representation
- `MemRealloc`: raw C allocation has no safe Janet representation

- `SetLoadFileTextCallback`: C file-IO hook; use Janet file functions instead

- `UnloadUTF8`: freed by the binding when load-utf8 returns
- `UnloadCodepoints`: freed by the binding when load-codepoints returns
- `TextCopy`: writes into a caller-owned C char buffer; Janet strings are immutable
- `TextFormat`: C printf-style varargs; use Janet string/format
- `TextAppend`: writes into a caller-owned C char buffer; Janet strings are immutable
- `UnloadWaveSamples`: freed by the binding when load-wave-samples returns
- `SetAudioStreamCallback`: callback runs on raylib's audio thread; a Janet VM is single-threaded
- `AttachAudioStreamProcessor`: callback runs on raylib's audio thread; a Janet VM is single-threaded
- `DetachAudioStreamProcessor`: callback runs on raylib's audio thread; a Janet VM is single-threaded
- `AttachAudioMixedProcessor`: callback runs on raylib's audio thread; a Janet VM is single-threaded
- `DetachAudioMixedProcessor`: callback runs on raylib's audio thread; a Janet VM is single-threaded
- `rlEnableStatePointer`: rlgl keeps the client-array pointer after the call returns
- `rlDisableStatePointer`: declared only for OpenGL 1.1 builds; the desktop build uses OpenGL 3.3
- `rlLoadExtensions`: raylib loads OpenGL extensions itself during init-window
- `rlSetShader`: rlgl keeps the locs pointer after the call returns; use begin-shader-mode

## Hand-written functions

- `gen-image-font-atlas` (`GenImageFontAtlas`): takes a glyph array and returns [image recs]; see src/manual.c
- `set-trace-log-capture`: queues raylib log messages from any thread instead of printing them
- `handle-live?`: whether a handle or array can still be used (not unloaded, owner not unloaded)
- `unload-materials`: unloads every material in an array from load-materials, then frees the array
- `unload-model-resources`: unloads a model and the distinct textures its materials reference, except those in keep
- `take-trace-logs`: drains queued log messages as [level message] tuples
